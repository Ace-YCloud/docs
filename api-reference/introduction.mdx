The YCloud API is a REST API that lets you send messages, manage contacts, configure webhooks, and more. All requests go to a single base URL and use JSON for request and response bodies.

**Base URL:** `https://api.ycloud.com/v2`

## Versioning

The current API version is **v2**. The version is part of the base URL. Breaking changes will be introduced under a new version prefix.

## Request format

- All request bodies must be JSON.
- Set the `Content-Type: application/json` header on every request that has a body.
- Responses are always JSON.

## Hello World — send a WhatsApp message

The example below sends a text message to a WhatsApp number.

<CodeGroup>

```bash cURL
curl -X POST https://api.ycloud.com/v2/whatsapp/messages/sendDirectly \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "YOUR_WHATSAPP_NUMBER",
    "to": "+14155552671",
    "type": "text",
    "text": {
      "body": "Hello from YCloud!"
    }
  }'
```

```javascript Node.js
const response = await fetch(
  'https://api.ycloud.com/v2/whatsapp/messages/sendDirectly',
  {
    method: 'POST',
    headers: {
      'X-API-Key': 'YOUR_API_KEY',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      from: 'YOUR_WHATSAPP_NUMBER',
      to: '+14155552671',
      type: 'text',
      text: { body: 'Hello from YCloud!' },
    }),
  }
);
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    'https://api.ycloud.com/v2/whatsapp/messages/sendDirectly',
    headers={
        'X-API-Key': 'YOUR_API_KEY',
        'Content-Type': 'application/json',
    },
    json={
        'from': 'YOUR_WHATSAPP_NUMBER',
        'to': '+14155552671',
        'type': 'text',
        'text': {'body': 'Hello from YCloud!'},
    },
)
print(response.json())
```

</CodeGroup>

## SDKs

Official SDKs are available for the following languages:

| Language   | Package / Repository                              |
| ---------- | ------------------------------------------------- |
| Node.js    | `@ycloud-cpaas/ycloud-sdk-node`                  |
| Python     | `ycloud-sdk-python`                               |
| PHP        | `ycloud-cpaas/ycloud-sdk-php`                     |
| Java       | `com.ycloud:ycloud-sdk-java`                      |
| Go         | `github.com/ycloud-cpaas/ycloud-sdk-go`           |
| Ruby       | `ycloud-sdk-ruby`                                 |

<Tip>
  Use an SDK to avoid writing boilerplate authentication and serialization code. Each SDK mirrors the REST API one-to-one.
</Tip>
