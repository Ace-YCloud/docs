---

The Balance API lets you check the current credit balance of your YCloud account. Use this to monitor prepaid credit levels and trigger top-up alerts.

## Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| `GET`  | `/balance` | Retrieve balance |

---

## Retrieve balance

`GET https://api.ycloud.com/v2/balance`

Returns the current balance for your account.

<CodeGroup>

```bash cURL
curl https://api.ycloud.com/v2/balance \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch('https://api.ycloud.com/v2/balance', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' },
});
const balance = await response.json();
console.log(balance.availableBalance);
```

```python Python
import requests

response = requests.get(
    'https://api.ycloud.com/v2/balance',
    headers={'X-API-Key': 'YOUR_API_KEY'},
)
data = response.json()
print(data['availableBalance'])
```

```php PHP
$ch = curl_init('https://api.ycloud.com/v2/balance');
curl_setopt($ch, CURLOPT_HTTPHEADER, ['X-API-Key: YOUR_API_KEY']);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = json_decode(curl_exec($ch), true);
echo $response['availableBalance'];
```

</CodeGroup>

### Response fields

<ResponseField name="currency" type="string">
  The currency of the balance amounts (e.g., `USD`).
</ResponseField>

<ResponseField name="availableBalance" type="number">
  The amount of credit currently available to spend. This excludes any credit that is reserved for pending transactions.
</ResponseField>

<ResponseField name="totalBalance" type="number">
  The total credit balance including both available and reserved amounts.
</ResponseField>

### Example response

```json
{
  "currency": "USD",
  "availableBalance": 247.50,
  "totalBalance": 250.00
}
```

<Note>
  YCloud uses a prepaid credit model. Messages are charged from your `availableBalance` at send time. Add credits from the **Billing** section of the YCloud dashboard.
</Note>

<Tip>
  Use this endpoint in a scheduled job to alert your team when `availableBalance` falls below a threshold, preventing failed message deliveries.
</Tip>
