---
title: "Contacts"
description: "Create, retrieve, update, and delete contacts, and list contact attributes."
---

The YCloud Contacts API lets you manage your customer contact database. Contacts store phone numbers, email addresses, and custom attributes that can be used to personalize messages and trigger automation journeys.

## Endpoints

| Method   | Path | Description |
| -------- | ---- | ----------- |
| `POST`   | `/contacts` | Create a contact |
| `GET`    | `/contacts` | List contacts |
| `GET`    | `/contacts/{id}` | Retrieve a contact |
| `PATCH`  | `/contacts/{id}` | Update a contact |
| `DELETE` | `/contacts/{id}` | Delete a contact |
| `GET`    | `/contact/attributes` | List contact attributes |

---

## Create a contact

`POST https://api.ycloud.com/v2/contacts`

### Request parameters

<ParamField body="nickname" type="string">
  Display name for the contact.
</ParamField>

<ParamField body="phoneNumber" type="string">
  Phone number in E.164 format (e.g., `+14155552671`).
</ParamField>

<ParamField body="countryCode" type="string">
  ISO 3166-1 alpha-2 country code (e.g., `US`, `GB`, `BR`).
</ParamField>

<ParamField body="email" type="string">
  Email address.
</ParamField>

<ParamField body="tags" type="array">
  Array of tag strings to categorize the contact.
</ParamField>

<ParamField body="customAttributes" type="object">
  Key-value pairs for custom attributes defined in your account.
</ParamField>

<CodeGroup>

```bash cURL
curl -X POST https://api.ycloud.com/v2/contacts \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "nickname": "Jane Doe",
    "phoneNumber": "+14155552671",
    "countryCode": "US",
    "email": "jane@example.com",
    "tags": ["vip", "customer"],
    "customAttributes": {
      "plan": "premium",
      "accountId": "ACC-00123"
    }
  }'
```

```javascript Node.js
const response = await fetch('https://api.ycloud.com/v2/contacts', {
  method: 'POST',
  headers: {
    'X-API-Key': 'YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    nickname: 'Jane Doe',
    phoneNumber: '+14155552671',
    countryCode: 'US',
    email: 'jane@example.com',
    tags: ['vip', 'customer'],
    customAttributes: {
      plan: 'premium',
      accountId: 'ACC-00123',
    },
  }),
});
const contact = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.ycloud.com/v2/contacts',
    headers={
        'X-API-Key': 'YOUR_API_KEY',
        'Content-Type': 'application/json',
    },
    json={
        'nickname': 'Jane Doe',
        'phoneNumber': '+14155552671',
        'countryCode': 'US',
        'email': 'jane@example.com',
        'tags': ['vip', 'customer'],
        'customAttributes': {
            'plan': 'premium',
            'accountId': 'ACC-00123',
        },
    },
)
```

</CodeGroup>

## List contacts

`GET https://api.ycloud.com/v2/contacts`

Returns a paginated list of contacts.

### Query parameters

<ParamField query="pageSize" type="number" default="20">
  Number of records per page (1–100).
</ParamField>

<ParamField query="pageToken" type="string">
  Pagination cursor.
</ParamField>

<ParamField query="filter" type="string">
  Filter expression (e.g., `phoneNumber="+14155552671"`).
</ParamField>

<CodeGroup>

```bash cURL
curl "https://api.ycloud.com/v2/contacts?pageSize=20" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch(
  'https://api.ycloud.com/v2/contacts?pageSize=20',
  { headers: { 'X-API-Key': 'YOUR_API_KEY' } }
);
```

</CodeGroup>

## Update a contact

`PATCH https://api.ycloud.com/v2/contacts/{id}`

Updates one or more fields on a contact. Only the fields you provide are changed.

<CodeGroup>

```bash cURL
curl -X PATCH https://api.ycloud.com/v2/contacts/cont_01h9xyz \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"nickname": "Jane Smith", "tags": ["vip"]}'
```

</CodeGroup>

---

## Delete a contact

`DELETE https://api.ycloud.com/v2/contacts/{id}`

Permanently removes the contact from your account.

<Warning>
  Deleting a contact is irreversible. This also removes the contact from all segments and may affect active journeys.
</Warning>

<CodeGroup>

```bash cURL
curl -X DELETE https://api.ycloud.com/v2/contacts/cont_01h9xyz \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## List contact attributes

`GET https://api.ycloud.com/v2/contact/attributes`

Returns all custom attribute definitions configured for your account.

<CodeGroup>

```bash cURL
curl https://api.ycloud.com/v2/contact/attributes \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

<ResponseField name="items" type="array">
  Array of attribute definitions.
  <Expandable title="attribute properties">
    <ResponseField name="name" type="string">
      Attribute key name.
    </ResponseField>
    <ResponseField name="displayName" type="string">
      Human-readable label shown in the dashboard.
    </ResponseField>
    <ResponseField name="type" type="string">
      Attribute type: `string`, `number`, `boolean`, `date`.
    </ResponseField>
  </Expandable>
</ResponseField>
