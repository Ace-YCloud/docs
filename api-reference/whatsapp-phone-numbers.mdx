---
title: "WhatsApp phone numbers"
description: "Manage WhatsApp Business phone numbers: list, retrieve, update profiles, configure commerce settings, and register numbers."
---

WhatsApp phone numbers are registered under a WhatsApp Business Account (WABA). Each number has a profile (name, description, photo) that users see when they receive messages. You can also configure commerce settings and update display names.

## Endpoints

| Method  | Path | Description |
| ------- | ---- | ----------- |
| `GET`   | `/whatsapp/phoneNumbers` | List phone numbers |
| `GET`   | `/whatsapp/phoneNumbers/{phoneNumber}` | Retrieve a phone number |
| `GET`   | `/whatsapp/phoneNumbers/{phoneNumber}/profile` | Retrieve phone number profile |
| `PATCH` | `/whatsapp/phoneNumbers/{phoneNumber}/profile` | Update phone number profile |
| `GET`   | `/whatsapp/phoneNumbers/{phoneNumber}/commerceSettings` | Retrieve commerce settings |
| `PATCH` | `/whatsapp/phoneNumbers/{phoneNumber}/commerceSettings` | Update commerce settings |
| `POST`  | `/whatsapp/phoneNumbers/{phoneNumber}/register` | Register a phone number |
| `GET`   | `/whatsapp/phoneNumbers/{phoneNumber}/settings` | Retrieve phone number settings |
| `POST`  | `/whatsapp/phoneNumbers/{phoneNumber}/settings` | Save phone number settings |
| `PATCH` | `/whatsapp/phoneNumbers/{phoneNumber}/displayName` | Update display name |

---

## List phone numbers

`GET https://api.ycloud.com/v2/whatsapp/phoneNumbers`

Returns all WhatsApp phone numbers in your account.

<CodeGroup>

```bash cURL
curl "https://api.ycloud.com/v2/whatsapp/phoneNumbers" \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch(
  'https://api.ycloud.com/v2/whatsapp/phoneNumbers',
  { headers: { 'X-API-Key': 'YOUR_API_KEY' } }
);
const { items } = await response.json();
```

</CodeGroup>

### Response fields

<ResponseField name="items" type="array">
  Array of phone number objects.
  <Expandable title="phone number properties">
    <ResponseField name="phoneNumber" type="string">
      The phone number in E.164 format.
    </ResponseField>
    <ResponseField name="wabaId" type="string">
      The WABA this number belongs to.
    </ResponseField>
    <ResponseField name="displayName" type="string">
      The display name shown to WhatsApp users.
    </ResponseField>
    <ResponseField name="status" type="string">
      Number status: `CONNECTED`, `OFFLINE`, `FLAGGED`, `RESTRICTED`, `BANNED`.
    </ResponseField>
    <ResponseField name="qualityRating" type="string">
      Quality rating: `GREEN`, `YELLOW`, `RED`.
    </ResponseField>
    <ResponseField name="messagingLimitTier" type="string">
      Current messaging limit tier.
    </ResponseField>
  </Expandable>
</ResponseField>

## Update phone number profile

`PATCH https://api.ycloud.com/v2/whatsapp/phoneNumbers/{phoneNumber}/profile`

Updates the business profile visible to WhatsApp users.

<ParamField body="about" type="string">
  Short description shown on the business profile (max 139 characters).
</ParamField>

<ParamField body="address" type="string">
  Physical address of the business.
</ParamField>

<ParamField body="description" type="string">
  Longer description of the business.
</ParamField>

<ParamField body="email" type="string">
  Business contact email shown on the profile.
</ParamField>

<ParamField body="websites" type="array">
  Array of website URLs (max 2).
</ParamField>

<ParamField body="vertical" type="string">
  Business category (e.g., `RETAIL`, `EDUCATION`, `HEALTH`).
</ParamField>

<CodeGroup>

```bash cURL
curl -X PATCH \
  "https://api.ycloud.com/v2/whatsapp/phoneNumbers/+14155550100/profile" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "about": "We help businesses grow with WhatsApp.",
    "email": "support@yourcompany.com",
    "websites": ["https://www.yourcompany.com"],
    "vertical": "RETAIL"
  }'
```

```javascript Node.js
await fetch(
  'https://api.ycloud.com/v2/whatsapp/phoneNumbers/+14155550100/profile',
  {
    method: 'PATCH',
    headers: {
      'X-API-Key': 'YOUR_API_KEY',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      about: 'We help businesses grow with WhatsApp.',
      email: 'support@yourcompany.com',
      websites: ['https://www.yourcompany.com'],
      vertical: 'RETAIL',
    }),
  }
);
```

</CodeGroup>

## Register a phone number

`POST https://api.ycloud.com/v2/whatsapp/phoneNumbers/{phoneNumber}/register`

Registers a phone number with the WhatsApp Business API. This is required before you can send messages from a new number.

<CodeGroup>

```bash cURL
curl -X POST \
  "https://api.ycloud.com/v2/whatsapp/phoneNumbers/+14155550100/register" \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Update display name

`PATCH https://api.ycloud.com/v2/whatsapp/phoneNumbers/{phoneNumber}/displayName`

Requests a change to the display name shown to WhatsApp users. Display name changes are subject to Meta's review.

<ParamField body="displayName" type="string" required>
  The new display name (must comply with Meta's display name policies).
</ParamField>

<CodeGroup>

```bash cURL
curl -X PATCH \
  "https://api.ycloud.com/v2/whatsapp/phoneNumbers/+14155550100/displayName" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"displayName": "YCloud Support"}'
```

</CodeGroup>

<Note>
  Display name changes may take up to 24 hours to be approved by Meta. The number continues to use the existing name until approval.
</Note>
