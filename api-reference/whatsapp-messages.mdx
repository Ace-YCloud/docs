---
title: "WhatsApp messages"
description: "Send, enqueue, and retrieve WhatsApp messages. Includes text, template, media, and interactive message types."
---

The WhatsApp Messages API lets you send outbound messages from your WhatsApp Business phone number to any WhatsApp user.

## Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| `POST` | `/whatsapp/messages/sendDirectly` | Send a message directly (synchronous) |
| `POST` | `/whatsapp/messages` | Enqueue a message (asynchronous) |
| `GET`  | `/whatsapp/messages/{id}` | Retrieve a message |
| `POST` | `/whatsapp/inboundMessages/{id}/markAsRead` | Mark an inbound message as read |
| `POST` | `/whatsapp/inboundMessages/{id}/typingIndicator` | Mark as read and show typing indicator |

---

## Send a message directly

`POST https://api.ycloud.com/v2/whatsapp/messages/sendDirectly`

Sends a message immediately and returns the result synchronously.

### Request parameters

<ParamField body="from" type="string" required>
  Your WhatsApp Business phone number in E.164 format (e.g., `+14155550100`).
</ParamField>

<ParamField body="to" type="string" required>
  The recipient's WhatsApp phone number in E.164 format.
</ParamField>

<ParamField body="type" type="string" required>
  The message type. One of: `text`, `template`, `image`, `document`, `audio`, `video`, `sticker`, `location`, `contacts`, `interactive`, `reaction`.
</ParamField>

<ParamField body="text" type="object">
  Required when `type` is `text`.
  <Expandable title="text properties">
    <ParamField body="body" type="string" required>
      The message text. Supports WhatsApp formatting (bold, italic, etc.).
    </ParamField>
    <ParamField body="previewUrl" type="boolean">
      Whether to enable link preview. Defaults to `false`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="template" type="object">
  Required when `type` is `template`. See template message example below.
</ParamField>

<ParamField body="image" type="object">
  Required when `type` is `image`. Contains `link` (URL) or `id` (media ID) and optional `caption`.
</ParamField>

<ParamField body="document" type="object">
  Required when `type` is `document`. Contains `link` or `id`, optional `caption` and `filename`.
</ParamField>

<ParamField body="interactive" type="object">
  Required when `type` is `interactive`. Contains `type` (e.g., `button`) and interactive components.
</ParamField>

<ParamField body="context" type="object">
  Quote a previous message by setting `messageId` to the ID of the message to reply to.
</ParamField>

### Text message

<CodeGroup>

```bash cURL
curl -X POST https://api.ycloud.com/v2/whatsapp/messages/sendDirectly \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "+14155550100",
    "to": "+14155552671",
    "type": "text",
    "text": {
      "body": "Hello! How can we help you today?"
    }
  }'
```

```javascript Node.js
const response = await fetch(
  'https://api.ycloud.com/v2/whatsapp/messages/sendDirectly',
  {
    method: 'POST',
    headers: {
      'X-API-Key': 'YOUR_API_KEY',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      from: '+14155550100',
      to: '+14155552671',
      type: 'text',
      text: { body: 'Hello! How can we help you today?' },
    }),
  }
);
```

</CodeGroup>

### Template message

<CodeGroup>

```bash cURL
  -H "Content-Type: application/json" \

        "code": "en"

      "components": [
        {
          "type": "body",
          "parameters": [
            { "type": "text", "text": "John" },
            { "type": "text", "text": "#ORD-12345" }

        }
      ]

```

```javascript Node.js
const response = await fetch(
```

## Enqueue a message

`POST https://api.ycloud.com/v2/whatsapp/messages`

Submits a message to YCloud's send queue. Use this endpoint for high-throughput sending. The request and parameters are identical to `sendDirectly`, but the response is returned immediately and delivery happens asynchronously. Subscribe to the `whatsapp.message.updated` webhook to track delivery status.

---

## Retrieve a message

`GET https://api.ycloud.com/v2/whatsapp/messages/{id}`

Returns the current state of a previously sent message.

<CodeGroup>

```bash cURL
curl https://api.ycloud.com/v2/whatsapp/messages/msg_01h9xyz \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch(
  'https://api.ycloud.com/v2/whatsapp/messages/msg_01h9xyz',
  { headers: { 'X-API-Key': 'YOUR_API_KEY' } }
);
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="string">
  Unique message ID.
</ResponseField>

<ResponseField name="wabaId" type="string">
  The WhatsApp Business Account ID that sent the message.
</ResponseField>

<ResponseField name="from" type="string">
  The sender's WhatsApp phone number.
</ResponseField>

<ResponseField name="to" type="string">
  The recipient's phone number.
</ResponseField>

<ResponseField name="type" type="string">
  Message type (e.g., `text`, `template`).
</ResponseField>

<ResponseField name="status" type="string">
  Delivery status: `accepted`, `sent`, `delivered`, `read`, `failed`.
</ResponseField>

<ResponseField name="createTime" type="string">
  ISO 8601 timestamp when the message was created.
</ResponseField>

<ResponseField name="error" type="object">
  Present only if `status` is `failed`. Contains `code` and `message` from Meta.
</ResponseField>

## Mark as read

`POST https://api.ycloud.com/v2/whatsapp/inboundMessages/{id}/markAsRead`

Marks an inbound message as read, which sends a read receipt to the sender.

<CodeGroup>

```bash cURL
curl -X POST \
  https://api.ycloud.com/v2/whatsapp/inboundMessages/msg_inbound_01h/markAsRead \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Typing indicator

`POST https://api.ycloud.com/v2/whatsapp/inboundMessages/{id}/typingIndicator`

Marks the message as read and displays a typing indicator to the sender for a short period.

<CodeGroup>

```bash cURL
curl -X POST \
  https://api.ycloud.com/v2/whatsapp/inboundMessages/msg_inbound_01h/typingIndicator \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>
