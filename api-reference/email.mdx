The YCloud Email API lets you send emails programmatically. It supports both plain text and HTML content.

## Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| `POST` | `/emails` | Send an email |

---

## Send an email

`POST https://api.ycloud.com/v2/emails`

### Request parameters

<ParamField body="to" type="string" required>
  The recipient's email address (e.g., `user@example.com`).
</ParamField>

<ParamField body="from" type="string">
  The sender's email address. If omitted, your default verified sender address is used.
</ParamField>

<ParamField body="subject" type="string" required>
  The email subject line.
</ParamField>

<ParamField body="contentType" type="string" required>
  The content type of the email body. Use `text/plain` for plain text or `text/html` for HTML.
</ParamField>

<ParamField body="content" type="string" required>
  The email body. For `text/html`, this can include HTML markup.
</ParamField>

<ParamField body="externalId" type="string">
  Your own identifier for this email, used for deduplication and tracking.
</ParamField>

<CodeGroup>

```bash cURL
curl -X POST https://api.ycloud.com/v2/emails \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "customer@example.com",
    "from": "hello@yourcompany.com",
    "subject": "Your order has shipped!",
    "contentType": "text/html",
    "content": "<h1>Good news!</h1><p>Your order #12345 is on its way.</p>"
  }'
```

```javascript Node.js
const response = await fetch('https://api.ycloud.com/v2/emails', {
  method: 'POST',
  headers: {
    'X-API-Key': 'YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    to: 'customer@example.com',
    from: 'hello@yourcompany.com',
    subject: 'Your order has shipped!',
    contentType: 'text/html',
    content: '<h1>Good news!</h1><p>Your order #12345 is on its way.</p>',
  }),
});
const email = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.ycloud.com/v2/emails',
    headers={
        'X-API-Key': 'YOUR_API_KEY',
        'Content-Type': 'application/json',
    },
    json={
        'to': 'customer@example.com',
        'from': 'hello@yourcompany.com',
        'subject': 'Your order has shipped!',
        'contentType': 'text/html',
        'content': '<h1>Good news!</h1><p>Your order #12345 is on its way.</p>',
    },
)
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="string">
  Unique email record ID.
</ResponseField>

<ResponseField name="to" type="string">
  The recipient's email address.
</ResponseField>

<ResponseField name="subject" type="string">
  The email subject.
</ResponseField>

<ResponseField name="status" type="string">
  Delivery status: `accepted`, `sent`, `delivered`, `bounced`, `failed`.
</ResponseField>

<ResponseField name="createTime" type="string">
  ISO 8601 timestamp when the email was submitted.
</ResponseField>

<Note>
  The sender address (`from`) must be verified in your YCloud account before you can send emails from it.
</Note>
