---
title: "WhatsApp Calling"
description: "Initiate, accept, and terminate WhatsApp calls programmatically using the Calling API."
---

The WhatsApp Calling API lets you manage voice calls over WhatsApp. You can connect outbound calls to your users, handle inbound call flows, and terminate calls from your server.

<Note>
  WhatsApp Calling is currently available to select businesses. Contact YCloud to enable this feature for your account.
</Note>

## Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| `POST` | `/whatsapp/calls/connect` | Connect (initiate) a call |
| `POST` | `/whatsapp/calls/{callId}/preAccept` | Pre-accept an inbound call |
| `POST` | `/whatsapp/calls/{callId}/accept` | Accept an inbound call |
| `POST` | `/whatsapp/calls/{callId}/terminate` | Terminate an active call |
| `POST` | `/whatsapp/calls/{callId}/reject` | Reject an inbound call |

## Connect a call

`POST https://api.ycloud.com/v2/whatsapp/calls/connect`

Initiates an outbound WhatsApp call to a user.

### Request parameters

<ParamField body="from" type="string" required>
  Your WhatsApp Business phone number in E.164 format.
</ParamField>

<ParamField body="to" type="string" required>
  The recipient's WhatsApp phone number in E.164 format.
</ParamField>

<CodeGroup>

```bash cURL
curl -X POST https://api.ycloud.com/v2/whatsapp/calls/connect \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "+14155550100",
    "to": "+14155552671"
  }'
```

```javascript Node.js
const response = await fetch(
  'https://api.ycloud.com/v2/whatsapp/calls/connect',
  {
    method: 'POST',
    headers: {
      'X-API-Key': 'YOUR_API_KEY',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      from: '+14155550100',
      to: '+14155552671',
    }),
  }
);
const call = await response.json();
console.log(call.id); // use this callId for subsequent operations
```

</CodeGroup>

### Response fields

<ResponseField name="id" type="string">
  Unique call ID. Use this in subsequent requests.
</ResponseField>

<ResponseField name="status" type="string">
  Initial call status, typically `initiated`.
</ResponseField>

<ResponseField name="from" type="string">
  The calling phone number.
</ResponseField>

<ResponseField name="to" type="string">
  The called phone number.
</ResponseField>

<ResponseField name="createTime" type="string">
  ISO 8601 timestamp when the call was created.
</ResponseField>

## Pre-accept a call

`POST https://api.ycloud.com/v2/whatsapp/calls/{callId}/preAccept`

Signals that your system is ready to handle the call before fully accepting it. This is used in IVR or routing scenarios to hold the caller briefly.

<CodeGroup>

```bash cURL
curl -X POST \
  https://api.ycloud.com/v2/whatsapp/calls/call_01h9xyz/preAccept \
  -H "X-API-Key: YOUR_API_KEY"
```

</CodeGroup>

## Call status updates

Subscribe to the following webhook events to track call state changes:

- `whatsapp.call.connect` — A call was connected.
- `whatsapp.call.status_updated` — Call status changed (e.g., ringing, answered).
- `whatsapp.call.terminate` — A call ended.
