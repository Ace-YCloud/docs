YCloud Inbox is a real-time chat tool built on WhatsApp. It lets your customer service and sales teams manage all conversations from one place, collaborate internally, and track performance with built-in analytics.

## Key features

<CardGroup cols={2}>
  <Card title="Shared inbox" icon="inbox">
    Every agent on your team sees and handles conversations from the same WhatsApp number. Internal notes and transfers keep everyone in sync.
  </Card>
  <Card title="Agent assignment" icon="user-check">
    Multiple agents can be active on the same WhatsApp account. Conversations are automatically routed to available agents using configurable assignment rules.
  </Card>
  <Card title="Customer data" icon="address-card">
    View and edit customer details directly from the chat window. Rich background information and segmentation data help every agent pick up where someone else left off.
  </Card>
  <Card title="Analytics reports" icon="chart-bar">
    Automatically generated reports across multiple dimensions let you track team performance, response times, resolution rates, and more.
  </Card>
  <Card title="Rich media support" icon="paperclip">
    Send and receive emojis, images, videos, audio, files, and location information. Inbox uses Meta's official WhatsApp Cloud API.
  </Card>
  <Card title="AI Copilot" icon="sparkles">
    AI-powered summaries extract structured insights from conversations on transfer or closure, reducing manual effort and helping supervisors review work faster.
  </Card>
</CardGroup>

## Efficiency tools

**Advanced filtering** — Find target conversations quickly by combining multiple filter conditions: assignment status, contact tags, country, language, and more.

**Canned responses** — Save frequently sent messages with shortcodes. Type `/` in any chat to browse and insert them instantly.

**Welcome messages** — Automatically send a pre-set message when a customer first opens a conversation. Supports text, media, and interactive message types.

**Icebreaker messages** — Customizable, clickable prompt boxes shown to new users. They help customers navigate your services and can trigger chatbot workflows.

**Automatic replies** — Configure auto-replies for unassigned conversations or when an agent has not responded within a set time.

**Custom working hours** — Define your team's operating hours. Outside those hours, conversations can be routed to a chatbot automatically.

**Convenient integration** — Inbox exposes APIs and webhooks so you can connect external applications and customer service bots.
